# VentureOS

An open-source team of AI agents that takes a founder's idea from a short brief
through six gated phases — Discover, Validate, Build, Commercial setup, Launch,
Operate & learn — with **sourced evidence**, **founder approval at every gate**,
and a real **STOP** recommendation when the evidence doesn't support moving on.

Built for the MADS × CSEA AI Hackathon, Fall 2026.
